# Security, licensing and provenance audit

Audit snapshot: 2026-10-22, current `main` base `c2f8c622d21d3db804e57c9a02e4c09b264f9c4b`. This is a code and evidence review, not a penetration test, legal opinion, public deployment certification or human release approval. It follows issue #23 and the existing [asset security review](ASSET_SECURITY_RELEASE_REVIEW.md), [local boundary correction](LOCAL_SECURITY_BOUNDARY.md), and committed evidence under `asset-review-evidence/`.

## Trust boundaries and route inventory

The running app's FastAPI OpenAPI schema is the source of API route definitions. `/` is a local static frontend route excluded from OpenAPI. WebSockets are also absent from OpenAPI and are listed separately. When built assets exist, `/assets/*` is mounted through `LocalStaticFiles`; it rejects drive, UNC and backslash paths before filesystem resolution. No upload or arbitrary filesystem download endpoint exists. Package and analysis exports are generated from validated records; package export sets `no-store` and `nosniff`.

| Route group | Access and effects | Controls / limitations |
|---|---|---|
| `GET /health` | Public read | Reveals app health and whether optional narrative settings are present, not credentials or provider identity. |
| `GET /api/matches`, `/api/matches/{id}`, events, state, metrics, tactics, pass difficulty/evidence, insights/evidence, overlays, analysis export, package | Public reads of deterministic fixtures and imported synthetic records | Bounded pagination/query values where applicable; package export size limited to 2 MB/1,000 events. CSV is generated from typed fields. No per-user privacy boundary. |
| `POST /api/matches/generate` | Public deterministic computation; no persisted write | Seed is bounded to signed 32-bit nonnegative range. No IP-based rate limit. |
| `POST /api/matches/{id}/recap`, `/api/insights/{id}/explain` | Public deterministic computation; no persisted write | Pydantic/query validation; recap has no explicit rate limiting. Explain scans fixture/import records. |
| `GET /api/data-hub` | Public library and feature status read | Shows only whether import token length meets a minimum, never token value. Aggregates imported data. |
| `POST /api/matches/ingest`, `/api/data-hub/preview`, `/api/data-hub/import` | Mutating import or package work, bearer token required | Token must be configured with >=32 chars; constant-time comparison. Whole body <=2,000,000 actual bytes; strict package schema, 1,000-event and 100-match caps; SQLite immediate transaction and conflict checks. Shared token is not user identity; no rate limit. |
| `POST /api/data-hub/recover`, `/api/data-hub/matches/{id}/lifecycle` | Destructive or restorative administration | Import bearer plus explicit admin flag, direct loopback client and host, rejects forwarded headers; recovery requires deletion ID; lifecycle requires generation/revision and exact confirmation. This is deliberately unsupported behind a public proxy. |
| `GET /api/agent-traces`, `POST /api/insights/{id}/agent-run` | Admin operations | Admin token required with constant-time comparison; fail closed. Provider call also requires opt-in and endpoint/model configuration. No call in tests/startup. No endpoint-level quota/concurrency budget. |
| `/api/sandbox/*` REST | All stateful runtime operations require operator bearer token; data is owner-scoped | Token map is validated, unique and bounded to 100 owners; unauthorized or foreign owner returns generic inaccessible identity. SQLite limits bound scenarios, sessions, checkpoints, events, commands, runs and experiments. Per-session revisions/idempotency and transactions protect commands/replay. Private scenario lists/archive use `no-store`; other token-protected responses should be served over TLS in hosted deployments. |
| `WS /api/sandbox/sessions/{id}/observe` | Owner-scoped read stream | Exact first-frame token, <=4 KiB frame, 5-second auth timeout, Origin allowlist for supplied origins; revalidates token on each observation. Never put credentials in URL. |
| `WS /ws/matches/{id}` | Public read stream for public match data | Read-only. No token or Origin restriction because underlying data is public. Cursor is currently an unconstrained integer query parameter; unknown matches close 4404. |
| `/assets/*` and `/` | Public static reads | Local path containment plus Windows path rejection; built frontend assets are compile-time named. Root fallback returns a fixed message if no build exists. |

Audit-time verification added in `backend/tests/test_issue_23_security_audit.py` checks OpenAPI coverage, stateful sandbox authorization, import/admin denials, read-only public WebSocket behavior, private socket authentication, validation bounds and safe export response behavior. Existing `test_security_boundary.py`, `test_foundry_command_auth.py`, data-hub/lifecycle tests and runtime suites provide deeper checks for request size, hostile JSON, storage conflicts, rollback, owner isolation, token rotation and provider denial.

## Findings, controls and residual risk

| Finding | Status / evidence | Residual risk and owner action |
|---|---|---|
| Starlette Windows UNC static-file resolution and unbounded request bodies | **Fixed on main by #36.** FastAPI 0.143.3 / Starlette 1.3.1 pins and pre-resolution Windows path rejection; ASGI cap reads chunked bodies and returns 413. Sentinel tests make no SMB request. | Re-run dependency scanning as part of release; byte caps do not bound concurrent connections or request rate. |
| Ambiguous JSON (duplicate keys, nonfinite numbers, excessive nesting) at import/runtime boundaries | **Rejected** by request boundary; malformed syntax proceeds to FastAPI's 422. Focused data-hub tests cover duplicate keys, NaN, exponent overflow and deep nesting. | No attempt to parse non-JSON bodies as imports is made; schema remains endpoint-specific. |
| Shared imported-match writes can be abused if the import credential is enabled on a public host | **Not a per-user/public authorization design.** Writes fail closed when token absent; import is intended for authorized local/trusted use. | Keep import token unset for public demo unless fronted by a deliberate authorization/rate-limit design. Public rate limiting and per-principal quotas are absent. Owner: deployment/release maintainer. |
| Expensive public work and optional inference can be repeated | Inputs, page sizes, match counts, event counts and runtime experiment dimensions are bounded. No general API/IP rate limiter exists. Agent route requires admin credential but has no concurrency, spend or request quota enforcement. | Keep Foundry disabled by default and admin token private; add an operational gateway quota before public inference. Do not claim rate limiting exists. Owner: deployment maintainer. |
| Anonymous WebSocket match stream | Read-only view of already public match data; no state mutation or private session. | Main match feed has no origin check or connection cap; acceptable only while served dataset remains public and deployment enforces connection/resource controls as needed. |
| Host/CORS assumptions | CORS permits only local Vite origins and GET/POST, with explicitly listed headers. Raw HTTP boundary rejects duplicate/delimited Host and backslash paths. CORS is not authorization. Lifecycle checks actual direct loopback socket/host and rejects forwarded headers. | Hosted origin configuration and trusted proxy policy are deployment work; no reverse-proxy trust or forwarded-host auth is implemented. |
| Session/runtime isolation and SQLite integrity | Dedicated runtime DB must not share imported-match DB; owner included in storage access; writes use SQLite transactions, revision checks and idempotency. Temporary DB, concurrent, replay/branch and restart tests exist. | Local filesystem permissions, backup security, disk exhaustion and multi-process operational limits remain host responsibilities. No user account/session cookie architecture exists. |
| Error leakage and caching | Runtime handler maps SQLite/engine/corrupt snapshot failures to typed generic errors. Foundry failure returns exception class only; trace contains stage/status/error type, not exception text or prompt. Private scenario responses and package downloads are `no-store`; static asset cache policy is delegated to Starlette/build server. | Some import validation messages identify invalid field/event; these are user-supplied diagnostics. Review deployment reverse-proxy logging and cache headers before publishing private data. |
| Prompt injection/untrusted model output | Model receives deterministic insight and source events, not credentials. `audit_model_packet` requires exact keys, evidence IDs subset, size caps, no digits in narrative, and deterministic facts remain separate. Failure does not substitute model text as authoritative evidence. | This is a narrow output gate, not a general prompt-injection defense. Foundry is optional and disabled without explicit settings; human review required before enabling public output. |
| Secrets/logs/generated files | App reads credentials from environment; no checked-in `.env`, SQLite DB or build output identified in prior review. Traces are in-memory, capped to 50 and protected; errors record types only. | This checkout did not run a dedicated secret scanner. Operators must keep env files out of source control and redact process/CI logs. |
| Asset authorship/CC0 authority and application license | Seven procedural `.blend` sources and seven GLBs have SHA-256 hashes, generators and validation evidence. `external_assets` is empty; neutral original assets and existing notices are preserved. Asset release approval remains `pending-team-review`; root application/helper license is unspecified. | Rights holder must affirm authorship, authority to apply CC0, no undisclosed contributors, and choose/confirm application license. Never infer approval from hashes or the CC0 text. |

## Asset and dependency provenance

`assets/manifest.json` enumerates seven procedural assets with source/output paths, hashes, author declaration, CC0-1.0 declaration, generator, sizes, geometry and zero external assets/textures. Existing evidence includes native source audit, asset inventory, deterministic rebuilds, Khronos validation and runtime notice inventory. The committed `release_approval: pending-team-review` is intentionally unchanged. Technical derivation evidence does not establish copyright ownership or legal authority.

Frontend definitions are `frontend/package.json` plus committed `frontend/package-lock.json`; backend base definitions are exact pins in `backend/requirements.txt`; optional inference definitions are separately listed in `backend/requirements-foundry.txt` and are not part of the default install. `frontend/public/assets/THIRD_PARTY_NOTICES.txt`, `licenses/`, and `docs/asset-review-evidence/runtime-licenses.json` identify shipped frontend transitive notices and development-only validator licensing. No root software license exists. No DSTNS AGPL code/assets, commercial models, real match footage, club logos, player likenesses or unlicensed music were added by this audit.

On 2026-10-22, PyPA pip-audit 2.10.1 was run in an isolated Python 3.14.5 virtual environment against current `backend/requirements.txt`: 27 pinned and transitive packages, **0 known vulnerabilities** in the queried advisory service. Raw JSON is `asset-review-evidence/python-audit-issue-23.json`. `backend/requirements-foundry.txt` was not scanned because it is optional and depends on the same base requirements plus a separate large provider closure; it remains outside this result. This is an advisory database snapshot, not a guarantee of safety. Prior committed npm audit evidence from 2026-10-21 reports zero known vulnerabilities for the lockfile at that review. This environment has no Node/npm, so the frontend lockfile scan and requested npm install/build/e2e commands could not be rerun here. The full backend command `python -m pytest tests -q -p no:cacheprovider` passed **252 tests** on Python 3.14.5 (49.29 s; one Starlette/httpx deprecation warning). The repository GLB contract/hash script passed for all seven assets. Blender rebuild script could not run because Blender is absent. No legal approval follows from scanners.
